# 第 1 周｜MRI 重建论文阅读笔记

## 论文 1：C + Mag——结合复数与幅度信息的动态 MRI 重建

- **论文标题**：Harnessing Magnitude-Only and Complex Measurements for Improved Dynamic MRI Reconstruction with Learned Priors
- **作者**：Mahdi Saberi、Yaşar Utku Alçalar、Merve Gulle、Chetan Shenoy、Mehmet Akçakaya
- **年份**：2026（arXiv v2，2026-10-20；论文页眉为期刊排版稿，不能据此断言已正式发表）
- **论文链接**：https://arxiv.org/abs/2608.18036
- **方法名称**：C + Mag
- **关键词**：动态 MRI、k-space 幅度、数据一致性、PD-DL、ADMM 展开、相位恢复

### 研究问题

常规加速 MRI 重建主要使用目标时间帧已采集的复数 k-space 数据。在高加速率下，欠采样导致伪影和细节丢失。本文研究：能否**不增加扫描时间**，从相邻心动周期/时间帧中提取 k-space **幅度信息**，补充目标帧缺失位置的约束，而不错误地将相邻帧的相位当作目标帧相位？

### 核心创新点

1. **发现并利用动态 MRI 中 k-space 幅度的跨时间一致性。** 作者在 cine MRI 与相位对比 Flow2D MRI 中分析多线圈 k-space 幅度，发现相邻心动时相的幅度具有较高余弦相似度，因此可作为目标帧未采样位置的辅助信息。该发现为无需额外采集的幅度约束提供了依据。

2. **提出复数数据与幅度数据联合约束的 C + Mag 重建目标。** 目标帧已采样位置使用原始复数测量；相邻帧在目标帧未采样位置提供仅幅度的辅助测量。相比常规仅使用复数数据一致性的 PD-DL，额外引入幅度一致性：
   
   ```math
   min_x ||y_Ω - E_Ω x||₂² + λ ||r_Δ - |E_Δ x|||₂² + R(x)
   ```
   
   其中 Ω 为目标帧采样位置，Δ 位于 Ω 的补集，r_Δ 为邻近帧提供的幅度估计，R(x) 为学习型先验。**关键是只借用邻近帧的幅度，不借用其相位。**

3. **设计适配非光滑、非凸幅度约束的 ADMM 展开重建。** 使用 ADMM 将学习型近端正则化与数据一致性更新分开；对复数幅度项采用二次平滑近似 `|z| ≈ sqrt(|z|² + ε)` 以便求导，并在数据一致性子问题中使用 Nesterov 动量加速梯度更新，以改善优化稳定性。该幅度感知数据一致性模块可以结合空间或时空学习型正则化器。

4. **在多种动态 MRI 场景下验证实用性。** 涵盖回顾性欠采样 cine、Flow2D 和前瞻性欠采样实时 cine，并分析加速率、辅助帧数量与时间分布、平滑和优化策略；还包含心功能、血流定量及盲法心脏科专家评估。本文相较于早期会议版本扩展了优化与临床验证。

### 方法与网络结构（简述）

- 采用交错移位采样：不同时间帧采集不同 k-space 行；目标帧保留复数测量，邻近帧提供互补位置的幅度信息。
- 基于 ADMM 展开，共 **10 个展开阶段**；每个阶段的幅度感知数据一致性子问题使用 **10 次 Nesterov 加速梯度迭代**。
- 学习型近端算子采用 time-embedded U-Net（TE-UNet），分别测试仅空间（S）和时空（ST）正则化。
- 主要创新在**测量信息利用方式与数据一致性目标**，而非提出全新的 U-Net 主干。

### 主要实验结果

- **回顾性 cine MRI，R=8，空间正则化**：常规 PD-DL 为 **29.93 dB / 0.849 SSIM**，C + Mag 为 **38.67 dB / 0.963 SSIM**。
- **回顾性 cine MRI，R=16，时空正则化**：常规 PD-DL 为 **38.14 dB / 0.969 SSIM**，C + Mag 为 **38.99 dB / 0.972 SSIM**。时空基线更强，增益相对较小。
- **Flow2D，R=8，空间正则化**：平均相位差绝对误差由 **0.168 rad** 降至 **0.088 rad**，说明幅度约束也可帮助保留相位相关信息。
- 前瞻性实时 cine 的图像评估显示伪影减少、解剖结构更清晰；文中还报告了心功能和血流测量与参考值较好的一致性。

### 阅读总结与思考

**一句话概括**：通过利用相邻动态 MRI 帧之间相对稳定的 k-space 幅度，C + Mag 在不增加扫描时间的情况下，为欠采样重建增加了额外物理数据约束。

**值得关注**：创新重点不是更复杂的网络，而是挖掘已有采样数据中未被充分利用的信息，并将其明确写入数据一致性项。

**适用边界**：方法依赖跨帧 k-space 幅度具有足够一致性；对于剧烈运动或幅度变化明显的场景，其收益不能直接假定。作者实验主要围绕稳态动态心脏 MRI，不能直接推广到所有 MRI 任务。

**后续可研究**：幅度估计误差如何影响重建；辅助时间帧距离与加速率如何权衡；是否能推广到其他动态成像场景。

## 论文 2：LGGS——纵向 MRI 重建的引导组稀疏方法

- **论文标题**：LGGS: Longitudinal MRI Reconstruction via Guided Group Sparsity
- **方法名称**：LGGS（Longitudinal MRI Reconstruction via Guided Group Sparsity）
- **关键词**：纵向 MRI、参考扫描、组稀疏、循环注意力、相位不变匹配、原始–对偶展开

### 研究问题

纵向 MRI 是对同一患者在不同时间点进行重复扫描。历史扫描可以提供与当前解剖结构有关的先验，但两次扫描之间可能存在位置偏移、解剖变化和复数图像相位差。本文关注如何有效利用历史 MRI 引导当前欠采样重建，同时避免直接套用历史图像造成的错误结构迁移。

### 核心创新点

1. **纵向引导的组稀疏正则化。** 不是直接把历史图像作为当前图像的替代，而是利用历史 MRI 与当前图像之间的特征相似性，对组稀疏约束进行自适应引导，使历史信息参与正则化过程。

2. **相位不变的循环注意力机制。** 通过局部特征匹配缓解跨次扫描的空间错位，并利用对相位变化不敏感的相似性度量，减少 MRI 复数相位差对参考图像匹配的干扰。

3. **将引导组阈值算子融入可解释的展开网络。** 将稀疏先验对应的更新步骤与原始–对偶迭代结合，形成结构清晰的重建框架，而非完全依赖黑箱图像到图像映射。

4. **兼顾重建表现与模型紧凑性。** 论文报告模型参数量约 **108 万（1.08M）**，并在其所设置的纵向 MRI 重建实验中与比较方法进行定量及视觉对照。具体优势应以论文的测试数据和对比设置为准。

### 方法与网络结构（简述）

- **输入**：当前扫描的欠采样测量，以及同一患者既往扫描得到的参考 MRI。
- **参考信息对齐**：通过相位不变的局部循环注意力匹配历史与当前特征。
- **正则化**：使用参考信息引导的组稀疏/阈值操作，抑制欠采样伪影并保留当前图像的结构。
- **迭代求解**：将上述模块嵌入原始–对偶展开重建框架，结合测量数据一致性逐阶段更新。

### 实验结论与注意事项

- 论文在纵向 MRI 重建任务中报告了相较于所选基线的重建质量提升，并强调模型规模较小。
- **适用前提**：需要可用的同一患者历史扫描；历史与当前扫描差异较大时，参考信息的可靠性可能下降。
- **需进一步核对**：各数据集、加速倍率、PSNR/SSIM 数值及具体消融实验表格。这里不填入未经逐表核实的数字。

### 阅读总结与思考

**一句话概括**：LGGS 通过历史 MRI 的相位不变特征匹配来引导组稀疏正则化，再用展开网络完成当前扫描的欠采样重建。

**与论文 1（C + Mag）的区别**：C + Mag 主要挖掘动态序列相邻时间帧的 **k-space 幅度信息**，改善数据一致性；LGGS 主要利用同一患者**跨次扫描的历史图像信息**，改善先验正则化。二者利用的辅助信息来源不同，不能直接视为同一任务上的性能对比。

**后续值得思考**：当历史图像出现新病灶、病灶消失或较大解剖变化时，如何避免参考先验压制当前扫描中真实的新变化？
